On press
A press makes this the output device. The key lights up while it is. A press moves to the next ticked device. Tick two for a simple toggle. A device that isn't connected is skipped.
About "applies to"

Windows keeps two defaults. Most programs use the default device. Call software such as Discord and Teams uses the default communications device, unless you picked a device inside the program itself.

Calls only lets one key move a call to your headset while music stays on the speakers.

A program that is set to a specific device in its own settings ignores both.

Key face
Windows gives each device two names. Automatic picks the one that tells your devices apart. The icon is guessed from the device's type and name; pick one here if it guesses wrong.
