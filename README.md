# StreamDeck

Stream Deck plugins by [Emil Berglund](https://github.com/EmilB04).

## Battery Monitor

Shows the battery level of auto-detected wireless peripherals — headsets, mice,
keyboards, controllers and paired Bluetooth devices — on a Stream Deck key.

Everything lives in **[`BatteryMonitor/`](BatteryMonitor/)**, including the
[full documentation](BatteryMonitor/README.md): supported devices, how each
provider reads its hardware, and how to build and deploy the plugin.
