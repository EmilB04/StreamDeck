About renaming

Names come from Windows or from the device itself, and some say nothing useful. Windows calls one of my phones 4, and unbranded Bluetooth gear often shows up as "Bluetooth device". Fix those here.

A key's Nickname does the same for one key and wins over a rename. Rename a device to change its name everywhere. Use a nickname when one key needs its own wording.

The plugin stores each name against the device's ID, so the name survives reconnects, reboots and the device being switched off.
