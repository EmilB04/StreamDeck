HeadsetControl is required for headsets
Without it, headsets can't report a battery level and show up under "No battery data". Other devices work without it.

When you run the installer, add it to PATH so the plugin can find it. If a headset still shows no level, restart Stream Deck. It picks up a new PATH entry on restart.

About the device list

Refresh rescans. A scan takes about 3 seconds, so use it after you switch a device on.

The key shows the Backup device while the main one is off or missing, and switches back when the main one returns. Pair a wireless keyboard with your wired one: you see the wireless battery while it's on and the wired keyboard while it's off.

No battery data: the plugin found the device, but it reports no level. Mains powered: it runs off its cable.

Set Power to "always plugged in" for wired gear the plugin can't identify, like a speaker. The key then draws a plug.

About checking

Each check starts helper processes and opens the device, so a short interval costs CPU. A press reads the device straight away.

Adapt checks every 15 sec while charging and every 30 sec when low. While the level holds it backs off to 10 min, and to 2 min while the device is off. Charging or low never slows below your interval, and a change in level resets the backoff.

About names and offline keys

This action hides Stream Deck's own Title field, so you name the key with Nickname. Deck title also writes Stream Deck's title over the image, in Stream Deck's font. Set it to Nickname to show the name above, or the device's own name when Nickname is empty.

Last level when off keeps the last level a disconnected device reported, faded, with a crossed-out circle. Turn it off to show a dash.

How long since it was seen puts the age before the name, as in "10h · DualSense". On a narrow face like the ring, the age can push the name off the key. Turn it off and the crossed-out circle still marks the level as old.

Time left replaces the device name with an estimate. The name line fits one or the other.

It reads measuring… until the level drops 3% over at least ten minutes. Devices that report in 10% steps can take a while to get there. After a charge it starts measuring again, because a discharge rate can't span a charge.

Which devices report a level
Headsets
HyperX, SteelSeries, Corsair, Logitech, Razer, Turtle Beach, Roccat and Astro, around 100 models. Needs HeadsetControl installed and on your PATH.
Mice & keyboards
Logitech, over its own receivers or paired directly. Asus ROG. Razer new
Controllers
PlayStation: DualSense, DualSense Edge and DualShock 4 new, over USB or Bluetooth. Xbox new: Bluetooth only, in four steps rather than a percentage.
Bluetooth LE
Phones, watches, styluses and anything else that publishes a battery service. Windows reads the level, so brand doesn't matter.
Everything else
Still listed, without a level. Cable-powered devices show a plug instead.

Not covered: SteelSeries, Corsair and Roccat mice and keyboards, where each model speaks its own protocol. Xbox pads on the wireless dongle or a cable. Nintendo pads. AirPods, which use Apple's own protocol.

I wrote the entries marked new from published protocol documentation and haven't tested them on hardware yet.

How devices are found

The plugin has no model list. It lists what this machine can see, so you get whatever is plugged in or paired right now. A device released tomorrow works if it speaks one of the protocols above.

Bluetooth LE devices report a level and nothing else, so the bolt appears once the level rises. Many wireless devices report in 10% steps, so expect the number to jump.
